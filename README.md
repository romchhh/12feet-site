# 12 Feet — Billiard Club & Gentlemen's Lounge

Лендінг більярдного клубу «12 Feet» (Братислава), переписаний на **Next.js 14 (App Router) + React 18 + TypeScript** з оригінального статичного HTML/CSS/JS.

## Структура проєкту

```
app/
  layout.tsx      — кореневий layout, підключення шрифтів Google Fonts, метадані
  page.tsx         — головна сторінка, збирає всі секції
  globals.css      — усі стилі (портовані 1:1 з оригінального <style>)
components/
  Hero.tsx         — хіро-секція з навігацією та заголовком
  Tables.tsx       — секція столів і цін
  Menu.tsx         — секція меню (кава/пиво)
  Booking.tsx      — форма бронювання (клієнтський компонент, useState)
  Footer.tsx       — футер з контактами
types/
  index.ts         — спільні TypeScript-типи
public/
  hero.jpg         — фонове фото хіро-секції (витягнуте з base64 оригіналу)
```

## Що змінилось порівняно з оригіналом

- Весь inline `<script>` для форми бронювання переписаний на React `useState`/`useMemo` у `components/Booking.tsx` — логіка розрахунку ціни (20€/год будні, 25€/год пʼятниця-неділя) збережена один в один.
- Base64-зображення фону хіро-секції винесене в окремий файл `public/hero.jpg` і підключається через звичайний шлях `/hero.jpg` — це прибирає ~180 КБ з CSS та дає браузеру нормальне кешування.
- HTML розбитий на логічні React-компоненти замість однієї сторінки.
- Дані (ціни, пункти меню) винесені в типізовані масиви на початку відповідних компонентів — легко редагувати без правок розмітки.
